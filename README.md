# Arbor

A local-first tool for browsing NeuroMorpho.Org's library of digitally reconstructed neuron and glia morphologies.

Built against the [NeuroMorpho.Org REST API](https://neuromorpho.org/apiReference.html), with local caching so repeated use doesn't hammer the public API.

## Status

Early planning stage. Design mockup and API feasibility notes done; implementation not started.
